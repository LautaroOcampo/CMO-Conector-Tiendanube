TiendaNube Connector for Odoo

Sync products, stock and orders with TiendaNube

External service required

This app integrates Odoo with the TiendaNube (Nuvemshop) API. You need a TiendaNube store and a partner application (Client ID / Client Secret). After OAuth authorization, product, stock and order data are exchanged with TiendaNube servers.

Main features

  • Export Odoo products to TiendaNube
  • Import products from TiendaNube into Odoo
  • Sync images, variants and attributes
  • Stock synchronization (manual or automatic)
  • OAuth 2.0 authentication and token management
  • Order sync via webhooks and scheduled polling
  • Auto-link publications to Odoo products by SKU
  • Pause / unpause publications based on minimum stock

How it works

  1. Install the module and open TiendaNube Configuration in Odoo.
  2. Enter Client ID and Client Secret from your TiendaNube partner app.
  3. Authorize the application (OAuth) to obtain access tokens and store ID.
  4. Import or create publications, then sync stock as needed.
  5. Enable webhooks and/or polling to import sales into Odoo.

Data & privacy

When authorized, the connector sends and receives data required for e-commerce operations (products, variants, stock, orders and related customer/shipping fields provided by TiendaNube). Credentials and tokens are stored in your Odoo database. No activation key is required; you keep ownership of your data at all times.
