Privacidad

Servicio externo y datos

El modulo usa la API de TiendaNube. Hace falta una tienda activa y una aplicacion de socio (Client ID, Client Secret y Store ID).

Una vez autorizado, se intercambian publicaciones, variantes, imagenes, stock, precios, pedidos y los datos de comprador y envio que envia TiendaNube. Las credenciales y los tokens viven en tu base. Sin clave de activacion y sin servidor de terceros.

Ayuda

Preguntas frecuentes

Que hace falta para conectar?
Una tienda de TiendaNube y una aplicacion de socio con Client ID, Client Secret y Store ID.
Donde se guardan los tokens?
Solo en tu base de Odoo. No hay servidor de terceros ni clave de activacion.
Las ventas entran solas?
Si. Con el webhook activo, cada venta se procesa al instante. El polling revisa lo que falto y no duplica pedidos.
Se factura sola?
Si lo activas. La venta puede crear el pedido, la entrega y la factura, con diario e impuesto configurables.
Se puede usar mas de una tienda?
Si. El conector admite varias cuentas de TiendaNube en la misma base.
Que pasa si el SKU no coincide?
Se puede usar un producto de respaldo para no frenar el pedido ni la factura. En el PDF queda el nombre de TiendaNube.
